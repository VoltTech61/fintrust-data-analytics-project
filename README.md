# FinTrust Digital Bank – Data Analytics Project

This repository documents my 4-week Data Analytics project completed as part of the AnalystLab Africa Experience Lab.

## Project Overview

FinTrust Digital Bank is a fictional digital banking organisation seeking to transform customer and transaction data into actionable business intelligence.

My role in the project is within the **Data Analytics Track**.

## Tools

- Excel
- SQL
- Power BI
- Git
- GitHub

## Project Roadmap

### Week 1 – Understand & Plan ✅
- Business understanding
- Data profiling
- Data-quality assessment
- Analytical questions
- KPI planning
- Dashboard wireframe
- Initial analysis plan

### Week 2 – Analyse & Prepare
- Data cleaning
- Exploratory data analysis
- KPI calculations
- SQL analysis
- Initial Power BI dashboard

### Week 3 – Develop & Integrate
- Complete dashboard
- Deeper analysis
- DAX measures
- Validate findings

### Week 4 – Test, Refine & Present
- Dashboard testing
- Refine insights and visuals
- Final recommendations
- Documentation
- Final presentation

## Repository Structure

- `week-1-understand-plan` – Business and data understanding, KPI planning and dashboard wireframe
- `week-2-analyse-prepare` – Data cleaning, SQL and exploratory analysis
- `week-3-dashboard` – Power BI dashboard and deeper analysis
- `week-4-final` – Final dashboard, report and presentation

## Data

The project uses synthetic customer and transaction datasets provided for the AnalystLab Africa Experience Lab.

The original project datasets are not included in this public repository.
